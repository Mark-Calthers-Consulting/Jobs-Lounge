# Report font assets

Static Geist Regular and SemiBold are vendored from the official
[vercel/geist-font v1.9.2 release](https://github.com/vercel/geist-font/tree/v1.9.2/fonts/Geist/ttf).
They are embedded in generated reports and never fetched from a third-party font
host at report time. See OFL.txt for the accompanying SIL Open Font License.

`/report-logo.png` is derived from the existing `/logo.svg` for PDF image support.
